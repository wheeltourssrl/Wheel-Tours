# Wheel Tours – website copy

Exact static copy of https://wheeltour.netlify.app/ (built React/Vite SPA: all pages, scripts, fonts, images and SVGs).

Live on GitHub Pages: https://wheeltourssrl.github.io/Wheel-Tours/

Because GitHub Pages serves this repo under `/Wheel-Tours/`, asset paths and the router `basename` were prefixed with `/Wheel-Tours`.
`404.html` is a copy of `index.html` so deep links (e.g. `/Wheel-Tours/tours`) work.
